# 一脉（Yimai）

一脉保存的不是一个人的答案，而是一个人寻找答案的过程。

它探索人工智能时代，人如何保持自己的连续性、判断力和探索能力。

这里公开思想、方法和思想形成中具有公共意义的转折；不公开私人生活、家庭成员信息、可组合识别身份的细节，也不直接公开原始聊天记录或私人认知数据。

## 当前状态

种子阶段。当前只留下它为什么存在，以及第一篇源文章。后续内容由真实的新理解、新问题和新实验推动，不预先搭建完整体系。

## 来源说明

`origin/一脉.md` 是基于人与 AI 的持续探索整理出的首发稿：其中的思想归属、公开范围和最终表述由人保留判断与决定；AI 负责整理、连接和提出表述建议。AI 提出的内容不会被倒写成人的原创，人明确认可的内容也不会抹去其曾经由 AI 提出的事实。

## 公开边界

公开思想的路径，保护承载思想的人。

过去提供理解，但不能规定未来。
